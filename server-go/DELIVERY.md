# Go版の導入結果

2026年11月15日、対象本家のサーバー機能をGoへ移植し、Linux実機への導入とGitHubへのpushを完了した。
本家のVue/TypeScript画面を保持し、更新されたキャプチャ・予約ランキング等の画面も取り込んだ。
本番は`-no-proxy`で稼働し、Python・FastAPI・Zendriver・OpenCVを実行時に使わない。
FFmpeg、QSVEncC、tsreadex、Akebi等のメディア・HTTPS用プログラムは引き続き使用する。

## 実機の運用状態

既存の現在ユーザーのPM2を維持し、Go本体だけを更新した。HTTPSの別プロセスは再起動していない。
Go PID2601332、HTTPS PID3416。証明書検証付きのHTTPS応答は200、検証結果0。
既存設定・DB・本体は更新前にバックアップした。新しいサービス管理方式への付け替えやOS設定変更は行っていない。

更新前後と再生試験後、実録画10PID・10ファイルの保持とサイズ増加を確認した。
既存のディスク制限も維持され、対象2台とも読み込み上限10,000,000bytes/秒だった。
稼働中のGoとその子プロセスにPythonはなかった。

本番の初回走査と背景解析は通常の継続処理として実行中。
確認時は初回313/5,160、背景2,669/4,107で、解析全件の完了を意味しない。
既存の解析失敗4件は増えていない。Missing 1,036件、Recorded 4,109件、Recording 14件を確認した。
