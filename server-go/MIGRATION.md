## 追加した機能

- EDCB の予約状態を番組表へ反映する。予約 ID・録画中・無効・競合を含む。
- EID の一時不一致をサービス三つ組と放送時間で照合し、暫定予約を重複割当しない。
- Go 単独運転のチャンネル・番組更新を起動時と設定周期に実行する。
- 実況勢いを 30 秒ごとに更新し、バックグラウンド更新を終了時にキャンセルする。
- `-version` と起動ログに配布バイナリの Git revision を記録する。
- 本家 TorneClient のトル数取得・地域別集約・母標準偏差による基準値・ランキングを Go へ移植。
- トル数は初回 EPG 更新後と 3 時間ごとに更新し、通信失敗時には全地域の前回値を保持する。
- 本家のマイグレーションから生成した 17 テーブル・21 索引を Go に組み込み、新規 DB の作成と既存 DB の追加列を処理する。
- スキーマ追加は単一トランザクションで行い、未対応の既存列構成ではデータを保持してロールバックする。
- キャプチャのタグ CRUD・タグ付け・お気に入りを Go で処理する。他ユーザーのタグは 404、一括追加はすべての ID を検証してから変更する。
- ライブ接続をエンコーダー起動前に登録し、キューへの書き込みと切断を排他する。起動失敗通知の取りこぼしと二重 close を防ぐ。
- キャプチャ画像の内容ハッシュによる重複排除、複数保存場所、番組情報、日付別件数、チャンネル・番組アルバム、ID/ハッシュ指定の画像取得、一括削除を Go へ移植した。
- キャプチャの初回走査と OS 通知による変更監視を実装。欠落したファイル情報は一週間保持し、保存先が読めない・大量欠落した場合は期限削除を見送る。
- Linux のネットワーク保存先は設定された間隔で再走査する。アップロードは 50 MiB 制限・画像全体の検査・内容照合・排他的作成・即時登録を行う。
- 従来のクライアント用のページ番号・画像名による API は互換経路として残している。本家の新しい API 応答はキーセット方式を使う。
- キャプチャスキャン・DB 最適化の新しい実行/進捗 API を追加した。HTTP 切断で処理を止めず、二重実行を 429 で返し、進捗取得では DB を参照しない。
- 録画スキャン・バックグラウンド解析の実行/進捗 API を追加し、起動時の一括スキャンと新規登録後の解析を接続した。
- 欠落した録画済みファイルは一週間保持し、保存先が読めない・空に見える・二割を超える新たな欠落がある場合には削除を見送る。戻った未変更ファイルは ID を保持して復帰する。
- 欠落中の録画は一覧・検索・詳細から除外する。ファイル単位の排他で監視・手動解析・欠落処理を同期し、旧 Go 版の日時切り捨て値を補正して不要な再解析を防ぐ。
- 手動のバックグラウンド解析は一部失敗でも残りを処理し、最終的に失敗を返す。サーバー終了で待機を中断し、進捗と排他状態を解除する。
- 新規 DB にも WAL モードを設定し、番組表の大量更新と一覧の読み取りを並行させる。
- サムネイルの高速シークで画像を取得できない場合は、直前からのデコード・先頭からのデコードで再試行する。それでも取得できない候補は本家と同じ黒画像にし、取得済みの画像を使う。
- 録画の代表サムネイルを同じ放送回のキャプチャで差し替える。画像の内容を照合し、同じ録画内容を参照する全レコードの更新番号を進める。

- 録画の排他はファイルごとに独立させ、同じ内容を再解析した場合もファイル日時を更新して次回の重複解析を防ぐ。

- EDCB・Mirakurun の空白見出しを直前の詳細文へ結合し、「【」で始まる継続項目だけ改行する。概要の補完は独立した項目の元の本文から行う。
