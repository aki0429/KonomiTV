# 本家機能との照合

対象: `tsukumijima/KonomiTV` master `687b904bb0a2cbb329596fd7b0368c09afe19a6c` (2026-11-14)。
完全移植は作業中。README の過去の「実装済み」は実機確認・現行本家との機能一致を保証しない。

## 追加した機能

- EDCB の予約状態を番組表へ反映する。予約 ID・録画中・無効・競合を含む。
- EID の一時不一致をサービス三つ組と放送時間で照合し、暫定予約を重複割当しない。
- Go 単独運転のチャンネル・番組更新を起動時と設定周期に実行する。
- 実況勢いを 30 秒ごとに更新し、バックグラウンド更新を終了時にキャンセルする。
- `-version` と起動ログに配布バイナリの Git revision を記録する。

## 継続する移植・検証

静的なルート比較は次で再実行できる。Python の標準ライブラリだけを使う開発用ツールであり、Go サーバーの実行時依存ではない。

```console
python server-go/tools/audit_upstream_routes.py --ref upstream/master
```

本家の 117 ルートのうち、25 ルートが現在の Go 登録にない。

- キャプチャ管理: 一括削除、セクション・チャンネル・番組一覧、タグ、お気に入り、ID 指定の画像配信。
- メンテナンス: 新しい非同期実行・状態 API (録画スキャン、解析、キャプチャスキャン、VACUUM)。
- 番組: トル数・トル数ランキング。
- 録画: キャプチャからの代表サムネイル差替。

登録済みルートにも未完了の処理があるため、ルート数だけで完了と判定しない。

- Twitter の実ブラウザー backend が `UnavailableBackend` のまま。
- サムネイルの顔検出・画像採点、MPEG-4/PSC の解析、EDCB 名前付きパイプ受信。
- Bluesky の大きい画像の WebP 変換。
- 本家で変わったキャプチャ DB スキーマと API 応答、番組詳細の継続見出し、設定検証。
- 本家のクライアント更新、Python を必要としない新規 DB 作成・更新と導入手順。
- 実機のライブ・録画再生・保存・予約・外部アカウント連携を含む動作検証。

Git 管理と実機のバイナリは revision と SHA-256 で照合する。設定、認証情報、録画、実機 DB は公開リポジトリへ含めない。
